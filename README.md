# smartLAB - Laboratory Management System

## Overview

A comprehensive laboratory management system for civil engineering testing facilities specializing in soil, concrete, and asphalt analysis.

## Project Structure

```
.
├── asphalt/                # Asphalt testing module
├── concrete/              # Concrete testing module  
├── soil/                  # Soil testing module
├── dashboard/            # Analytics and reporting
├── components.js         # Shared UI components
├── index.html            # Authentication/login page
├── library.html          # Standards documentation
├── favicon.ico           # Favicon
├── footer.html           # Footer component
├── header.html           # Header component
├── server.log            # System logs (to be rotated)
└── (new files...)        # Additional configuration files
```

## Key Features

### 🌐 Multi-Laboratory Management
- Professional interface for multiple construction materials testing
- Real-time analytics and reporting
- Sample tracking and project management

### 🧪 Material-Specific Testing
- **Asphalt Testing**: CBR, Marshall stability, flow tests, bitumen extraction
- **Concrete Testing**: Compressive strength, slump tests, air content
- **Soil Testing**: Classification, gradation, compaction, moisture, density tests

### 📊 Client Management
- Project and team management
- Equipment tracking
- Analytics and reporting
- Schedule and calendar management

### 🌍 International Support
- Arabic and English language support
- RTL (Right-to-Left) interface support

### 🔧 Technical Features
- Real-time QR code generation and scanning
- Excel and PDF export capabilities
- Authentication system
- Responsive design
- Modern UI components

## Quick Start

### Prerequisites
- Web browser with modern JavaScript support
- Internet connection for initial data sync

### Usage
1. Clone the repository
2. Open `index.html` in your browser
3. Sign in with your credentials
4. Navigate to the desired laboratory module (asphalt, concrete, or soil)
5. Select from available tests and follow the guided process

## Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript ES6+
- **Libraries**: QRCode.js, Chart.js, jQuery
- **Styling**: CSS3 animations and transitions
- **Distribution**: Static web application
