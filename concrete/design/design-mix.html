ACI 211.1
Standard Practice for Selecting Proportions for Normal, Heavyweight, and Mass Concrete. The primary US method using absolute volume.
ACI 318
Building Code Requirements for Structural Concrete. Defines w/c limits, exposure classes, and durability requirements.
ASTM C94
Standard Specification for Ready-Mixed Concrete. Defines tolerances, delivery, and testing requirements.
BS 8500 / EN 206
European concrete specification. Uses exposure classes (XC, XD, XS, XF, XA) and compressive strength classes (C20/25, etc.).
ECP 203
Egyptian Code for Concrete Mix Design. Defines cement types, aggregate requirements, and mix proportioning for Egyptian conditions.
ASTM C33 / C330
Standard Specification for Concrete Aggregates (normal weight / lightweight). Gradation limits for fine and coarse aggregates.
