# جهاز اختبار تكسير مكعبات الخرسانة — Arduino + HX711 + Load Cell

موقع تعليمي كامل (RTL، عربي) يشرح تصميم جهاز يحوّل مكبساً هيدروليكياً إلى جهاز قياس رقمي
لمقاومة ضغط مكعبات الخرسانة 150×150mm: يعرض القوة بالكيلو نيوتن kN، ويحسب الإجهاد
بالميجا باسكال MPa، ويرصد لحظة الانهيار تلقائياً.

## تشغيل الموقع

```bash
npm install
npm run dev      # للتطوير
npm run build    # ينتج نسخة static جاهزة للنشر في مجلد dist
```

## اللغات المدعومة

الموقع متعدد اللغات بالكامل (كل النصوص والجداول والمخططات مترجمة)، مع مبدّل لغة في
الشريط العلوي وحفظ الاختيار في المتصفح، ودعم تلقائي لاتجاه الصفحة RTL/LTR وخط مناسب
لكل نظام كتابة:

| اللغة | الرمز | الاتجاه |
|---|---|---|
| English (أساسية) | `en` | LTR |
| العربية | `ar` | RTL |
| Русский | `ru` | LTR |
| Français | `fr` | LTR |
| اردو | `ur` | RTL |
| हिन्दी | `hi` | LTR |
| 中文 | `zh` | LTR |
| 日本語 | `ja` | LTR |
| Deutsch | `de` | LTR |

ملفات الترجمة في `src/i18n/` (ملف لكل لغة + `types.ts` للمخطط).

## المحتوى

- صفحة الشرح: الفكرة، المكونات (8 قطع بصور)، التوصيلات (جداول + مخطط SVG)،
  التركيب الميكانيكي (مقطع SVG)، الحسابات + حاسبة تفاعلية، الموديلات، المعايرة، الأمان.
- صفحة الفيرم وير: كودان كاملان مع زرّي نسخ وتحميل `.ino`، شرح المكتبات وطريقة الرفع.
- محاكاة تفاعلية للاختبار في أعلى الصفحة (قوة ← ذروة ← انهيار ← إنذار).
- دعم كامل للطباعة / حفظ PDF من المتصفح.

## الفيرم وير

| الملف | الوصف |
|---|---|
| `firmware/concrete_tester_lcd.ino` | موديل بشاشة LCD 16x2 I2C + طنان |
| `firmware/concrete_tester_serial.ino` | موديل بدون شاشة — خرج CSV عبر Serial |

المكتبات المطلوبة (تثبَّت من Arduino IDE → Sketch → Include Library → Manage Libraries):

- `HX711` by Bogdan Necula
- `LiquidCrystal I2C` by Frank de Brabander
- `Wire` (مدمجة)

## الصور

صور القطع (Load Cell، HX711، Arduino Uno، LCD I2C، زر، طنان، مصدر تغذية، مكبس
هيدروليكي، ولحظة التكسير) هي صور منتجات توضيحية أُنشئت خصيصاً لهذا الدليل وتمثل
القطع الحقيقية من حيث الشكل والوظيفة.

## تحذير السلامة

اختبار تكسير الخرسانة خطر جداً وقد تتطاير شظايا بسرعة عالية. استخدم نظارة واقية
ودرع حماية ولا تقف أمام منطقة التكسير.
