SmartLab is a cutting-edge civil engineering laboratory automation platform developed by Fimto Soft, designed to fully digitize material testing, streamline operational workflows, and enforce strict quality control standards. The platform seamlessly replaces traditional paperwork with a comprehensive digital ecosystem built around four core pillars:

1. Real-Time Hardware & IoT Integration

The platform's standout feature is its ability to establish a direct, real-time data connection with low-cost, accessible hardware components (such as Arduino or ESP32 microcontrollers).

  • Flexible Connections: It streams sensor data directly via Web Serial (USB) on Chrome and Edge browsers, LAN / Network (Wi-Fi / Ethernet) using WebSockets, or Bluetooth (BLE).
  • Cost-Effective Sensors: It natively supports high-utility, budget-friendly engineering sensors including HX711 Load Cells (for force/weight), HC-SR04 Ultrasonic sensors (for digital slump and distance), DS18B20 digital probes (for concrete maturity temperature logging), and LVDT displacement sensors.

2. Strict Adherence to Global Standards

Every automated calculation, density tracking, and engineering formula executed within the system is rigorously cross-referenced with international testing codes:

  • American Standards: Fully compliant with ASTM and AASHTO guidelines for soils, concrete, and asphalt.
  • British/European Standards: Supports BS EN testing criteria.
  • Compliance Checks: The system instantly validates incoming data streams against specified standard criteria, highlighting any compliance failures or out-of-tolerance results.

3. Statistical Quality Control & Design Tools

Laboratories can track material performance trends over time using automated quality control methods and interactive engineering modules.

  • ACI 214 Control Charts: Laboratories can track material performance trends over time using automated Moving Average and Cumulative Sum (CUSUM) quality control charts to verify production stability.
  • Mix Design Calculators: Features interactive engineering modules, such as a concrete mix proportioning tool based on ACI 211.1 absolute volume methods, which computes precise batch weights instantly.
  • Dynamic Test Engine: An administrator utility allowing labs to configure custom test protocols, map brand-new sensor inputs, and define unique mathematical formulas to process hardware data.

4. Automated Operations & Reporting

Eliminates manual logging errors by generating professional, comprehensive laboratory reports with automated calculations and data management features.

  • Instant PDF Reports: Eliminates manual logging errors by generating professional, comprehensive laboratory reports complete with automatically calculated charts and data tables via jsPDF with a single click.
  • QR Specimen Tracking: Features a QR Specimen Tracking System for chain-of-custody logging from casting to testing.
  • Equipment Calibration Manager: An automated Equipment Calibration Manager to prevent testing with expired equipment.
  • Break Schedule Generator: A multi-age concrete Break Schedule Generator for managing curing schedules.
