🔄 Key Differences
USCS (ASTM D2487): - Based on particle size distribution AND plasticity - 15 groups: GW, GP, GM, GC, SW, SP, SM, SC, ML, CL, OL, MH, CH, OH, Pt - Well-graded vs poorly-graded distinction for coarse soils - Plasticity chart (A-line) for fine soils AASHTO M 145: - Developed for highway subgrade evaluation - 7 main groups: A-1 through A-7 (+ A-8 for peat) - Subgroups: a (granular) vs b (silt-clay) - Group Index (GI) quantifies quality within group - GI = 0 = best, GI > 20 = very poor Correlation Rules (approximate): - GW/GP → A-1-a / A-1-b - GM/GC → A-2-4 / A-2-5 / A-2-6 / A-2-7 - SW/SP → A-3 / A-1-b - SM/SC → A-2-4 / A-2-6 - ML/CL → A-4 / A-6 - MH/CH → A-5 / A-7

📐 Key Equations
Coefficient of Uniformity: Cu = D₆₀ / D₁₀ Coefficient of Curvature: Cc = (D₃₀)² / (D₁₀ × D₆₀) Well-graded gravel (GW): Cu ≥ 4 AND 1 ≤ Cc ≤ 3 Well-graded sand (SW): Cu ≥ 6 AND 1 ≤ Cc ≤ 3 A-Line: PI = 0.73 × (LL - 20) Above A-line: Clay (C) | Below A-line: Silt (M) or Organic (O) Group Index (AASHTO): GI = (F-35)[0.2+0.005(LL-40)] + 0.01(F-15)(PI-10) F = % passing #200 sieve (0-100) LL = Liquid Limit, PI = Plasticity Index GI ≥ 0 (negative set to 0)
