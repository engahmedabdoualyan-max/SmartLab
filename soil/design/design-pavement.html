📐 Structural Number Equation
SN = a₁D₁ + a₂D₂m₂ + a₃D₃m₃ a₁ = surface layer coefficient (AC ≈ 0.44) a₂ = base layer coefficient (crushed stone ≈ 0.14) a₃ = subbase layer coefficient (sand ≈ 0.11) m = drainage coefficient (1.0 good, 0.8 fair, 0.6 poor) D = layer thickness (inches)
📐 Rigid Pavement Design Equation (AASHTO 1993)
log₁₀(W₁₈) = ZᵣS₀ + 7.35 log₁₀(D+1) - 0.06 + log₁₀[ΔPSI / (4.5-1.5)] + (4.22 - 0.32 pₜ) log₁₀[Sc Cd (D^0.75 - 1.132) / (215.63 J (D^0.75 - 18.42/ (Ec/k)^0.25))] D = slab thickness (inches) Sc = modulus of rupture (psi) Ec = elastic modulus of concrete (psi) k = modulus of subgrade reaction (pci) J = load transfer coefficient Cd = drainage coefficient
